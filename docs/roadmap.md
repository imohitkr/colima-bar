# Roadmap

[Docs index](README.md)

These features are planned. They have no fixed dates.

- Keep the logs of auto-removed containers (`--rm`, testcontainers) that fail, for a few minutes after they exit.
- A kubectl context and namespace switcher.
- A global hotkey.
- A docker context switcher for remote daemons.

To suggest a feature, open a [feature request](https://github.com/imohitkr/colima-bar/issues/new/choose).
